# 专业中国象棋游戏（非国际象棋）

本项目是一个**模块化、可扩展**的中国象棋（象棋）前端应用，不依赖后端服务。

## 已实现能力

- 商业级界面体验：类象棋平台布局（左导航 / 中央棋盘舞台 / 右侧工具列）
- 棋盘装饰外框增强，边线棋子完整显示（不再出现半枚被裁切）
- 标准中国棋盘：9 条竖线、10 条横线、楚河汉界竖线断开、上下九宫斜线
- 棋子落在交叉点（非格子中心），并支持高亮/落点提示
- 完整基础规则（将/士/象/马/车/炮/兵）
- 规则修复：将帅照面纳入将军检测，保证将死/困毙判断准确
- 双方独立计时器（走棋切换时自动切换计时方）
- 保存/加载（localStorage，本地手动保存，页面自动恢复）
- 认输与和棋（简化版和棋：按钮即结束）
- 汉字记谱日志（如“炮二平五”），并附带坐标提示便于新手理解
- 移动端触摸优化：落点热区扩大到整格尺寸
- 悔棋增强：恢复完整历史（棋局+日志+计时）

## 项目结构

```text
.
├── index.html
├── styles.css
└── src
    ├── main.js        # UI/交互与状态管理
    ├── rules.js       # 走法与判定规则
    ├── notation.js    # 汉字记谱
    ├── storage.js     # 本地保存/加载
    └── constants.js
```

## 运行

直接打开 `index.html`，或使用静态服务器：

```bash
python3 -m http.server 4173
```

浏览器访问：`http://localhost:4173`
